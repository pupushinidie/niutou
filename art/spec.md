> **文件名、原始尺寸、帧数定了就不改**；非改不可时先改这里，在交接报告里写明并记 `gpipe note`。

> **简洁版和正式版（2026-10-09 流程）**
> - `public/art/` 里现在是**简洁版**：`art/lite.py` 全部用代码画（牌面、酒馆场景、动物头像、图标、特效帧），不含任何文字，能直接上线。首发验收和首发上线都用它。

## 1. 风格方向（开工拍板：西部酒馆，不许换）

- **题材**：西部小镇的牛仔酒馆。夜间是酒馆里面（绿呢牌桌、煤油灯、吧台、钢琴、弹簧门）；白天是从酒馆门廊往外看的沙漠小镇（牧场里的长角牛、仙人掌、红色平顶山、水塔、蓝天）。
  基准图：`~/projects/pipeline/games/niutou/assets/style-saloon-night.png`（原图 raw/scenes/saloon-night-s32.png）、`style-saloon-day.png`（saloon-day-s42.png）。
- **气氛**：轻松、好笑、暖。牛是「可爱的吉祥物 + 罚分标记」，不是猎物。
- **硬性禁忌**：
  - **任何地方都不画牛头骨**（拍板时答应过他：夜间样张墙上的长角牛头骨要去掉）。墙上的装饰换成马蹄铁、牛仔帽、套索、马鞍、空画框、星形警徽这类**不带字**的东西；提示词里不要出现 skull / mounted horns / longhorn trophy。
  - 不画字：招牌、海报、酒瓶标签、卡角都不能有字或像字的花纹（数字、文字一律代码画）。招牌只能是空白木牌。
  - 不画人（封面、场景都不要人；头像用动物）。不画枪、不画酒醉的样子。
  - 不像知名角色：不要像《玩具总动员》里的牛仔和马、《兰戈》的变色龙、兔八哥、威利狼、臭鼬佩佩；动物头像用普通毛色和自己的造型。
  - 牛头图标不用原版的「凶红牛头」，画成**圆脸、短小角、大眼睛**的可爱小牛脸。
- **光照**：夜间是暖黄的煤油灯光，从画面上方和牌桌两侧打下来，四周压暗（暗角）；白天是正午顶光，阴影短、偏蓝。所有小图（图标、头像、牌面）统一**左上方来光**：左上亮边、右下暗边。
- **描边**：小图（≤48px）一律 1px 深棕描边 `#2a1a10`（不用纯黑），透明底，四周裁干净。场景不加描边。牌面外框 1px `#2a1a10`，四角各缺 1px（圆角）。
- **像素密度**：
  - 桌面上 1 个原图像素 = 2 个屏幕像素（牌 lg 2×、图标 16/32 2×、头像 2×）；手机上牌 sm 2×、图标和头像 1×。全部整数倍。
  - 场景 512×288 是唯一的例外：铺满舞台（cover），不是整数倍，上面压一层暗色渐变（和欲罢不能 `.cs-stage` 一样），牌桌区域是不透明的毡面，看不到糊的地方。
  - 不用抗锯齿、不用半透明羽化边（危险格的斜纹、尘土特效可以用整块的半透明色）。

## 3. 牌的显示尺寸（按牌桌实测估）

**关键数字 ≥24px** 是硬约束：牌上的数字字形高度 × 显示倍数 ≥ 24。所以做两套牌：

| 套 | 单张原图 | 数字字形 | 2× | 3× | 4× |
|---|---|---|---|---|---|
| sm | 28×38 | 6×12（2px 笔画） | 56×76，字 24px | 84×114，字 36px | 112×152 |
| lg | 42×58 | 8×16（2px 笔画） | 84×116，字 32px | 126×174，字 48px | — |

sm 只给手机用（1× 时字只有 12px，**不许 1× 显示**，除非是不需要读数字的牌背）。

**估算用的固定尺寸**：顶栏 44（手机 40）、舞台内边距 12、提示条 36、排头（行号 + 这排牛头合计）56 宽、格子间距 6（手机 3）、排间距 8（手机 4）、桌面玩家小卡 200×92（头像 64）、右侧栏 300。

| 可视区域 | 4 排的牌 | 手牌 | 纵向合计 | 横向 | 结论 |
|---|---|---|---|---|---|
| 1440×790 | lg 2×（84×116） | lg 2×，一行 10 张（894 宽） | 44+12+36+8+(4×116+3×8+20)+8+(116+16)+12 = **760** | 排头 56 + 6 格 534 = 590；左右各 5 个玩家小卡（5×92+4×8=492 ≤ 508 排高）+ 侧栏 300 → 约 1290 | 放得下，余 30px |
| 1920×960 | lg 2× | lg 3×（126×174，一行 1314 宽） | 44+12+36+8+508+8+190+12 = **818** | 很宽裕 | 放得下；排用 lg 3× 要 984，超了，不推荐 |
| 1024×690 | lg 2× | sm 2×（56×76），提示条并进手牌那一行 | 44+12+508+8+(76+16)+12 = **676** | 590 + 左右玩家各 ~190 宽 → 1000，侧栏收进抽屉 | 放得下，余 14px，比较紧 |
| 390×664 | sm 2×（56×76），第 6 格用窄条 `danger-strip-sm` 2×（28×76） | sm 2×，两行各 5 张（296 宽），「确认」按钮放手牌右边 | 40+对手 2 行小卡 92+(4×76+3×4+12)+(2×76+4+8)+间距 24 = **648** | 5×56+4×3+3+28 = 323 + 排头 36 + 内边距 12 = **371** ≤ 390 | 放得下，余 16px；对手小卡 74×44（头像 32 1×） |

拿不准、要界面实测后定的：
1. 1024×690 只余 14px，若顶栏或玩家小卡比估的高，就把 4 排换成 sm 3×（84×114，和 lg 2× 一样大，每排省 2px）或者手牌改成两列竖排放右边。
2. 手机的排头（这排牛头合计）可能要缩成排首牌上方的小角标；第 6 格必须用窄条，全宽的 6 格会挤到 399px。
3. 10 人时的对手小卡在手机上排 2 行×5 个；更少人数时一行放下。人少（2–4 人）时桌面可以把手牌放到 lg 3×（1440 下纵向 818，不行；只有 1920 行）。

**牌面图集怎么用**：两套图集格子排法一样，**第 n 号格子（n = 0–104）在第 `n % 10` 列、第 `⌊n/10⌋` 行**。0 号是**牌背**，1–104 就是那张牌，105–109 空着（透明）。一张图一次加载，界面用 `background-position` 取格子（示例见第 7 节）。别人扣着的牌、牌堆（战术模式剩余张数）、翻牌动画的背面都用 0 号。

**牌面内容（全部代码画，不交给模型）**：底色按牛头数（第 2 节）；1px 深棕外框、四角缺 1px；内框一圈底色的暗色（sm 内缩 1、lg 内缩 2）；顶边 1px 亮线。数字居中，sm 用 6×12、lg 用 8×16 的 2px 笔画像素数字，浅底深字 + 浅色 1px 描边，深底奶白字 + 深棕描边。牛头：sm 5×5、lg 7×7 的小牛脸，排法 1 = 上 1；2 = 上 2；3 = 上 3；5 = 上 3 下 2；7 = 上 4 下 3（4 个之间留 1–2px 空，不能叠在一起）。
出图阶段可以改的：小牛脸换成从 PixelLab 选中的牛头图标手工缩出来的版本、加底纹和角花、牌背换成 PixelLab 出的图案；**不能改**格子尺寸、排法、数字字形高度。

## 5. 夜间 / 白天用哪张

| 东西 | 夜间版 | 白天版 |
|---|---|---|
| 牌桌背景 | `scene/night-{0,1}` | `scene/day-{0,1}` |
| 首页大图 | `scene/hero` | 同一张 |
| 毡面、木边、牌、空格、危险格 | 同一套 | 同一套（牌桌类名进 `day-palette.ts` 的 `keep`，保持深色毡面） |
| 图标、头像、特效 | 同一套（都有深棕描边，白底上也清楚） | 同一套 |
| `fx/lamp` | 显示 | 界面决定（建议藏） |

## 6. 精灵图怎么播

全部横排，`background-size: N*100% 100%`，`animation: steps(N, jump-none)`（见 guluga-pixel-ui）；尊重 `prefers-reduced-motion`（只显示第 0 帧）。

| 文件 | 帧 | 每帧 | 播法 |
|---|---|---|---|
| `ui/thinking` | 4 | 250ms | 循环 |
| `fx/dust` | 6 | 60ms | 一次，`forwards` 停在空帧 |
| `fx/heads-pop` | 6 | 90ms | 一次，`forwards` |
| `fx/sparkle` | 6 | 120ms | 循环 |
| `fx/lamp` | 4 | 150ms | 循环 |
| `sprites/calf-run` | 6 | 80ms | 循环（同时用 transform 平移） |
| `sprites/tumbleweed` | 8 | 80ms | 循环（同时平移，一次滚过约 1.2 秒） |

## 7. 给界面的接入示例（`apps/web/src/art.ts` 归界面，照这个改）

```ts
const ROOT = `${import.meta.env.BASE_URL}art/`;
export const CARD = {
  sm: { w: 28, h: 38, src: `${ROOT}cards/cards-sm.png` },
  lg: { w: 42, h: 58, src: `${ROOT}cards/cards-lg.png` },
} as const;
/** n = 1–104 是牌，0 是牌背；scale 是整数倍。 */
export function cardStyle(n: number, size: keyof typeof CARD, scale: number) {
  const { w, h, src } = CARD[size];
  return {
    width: w * scale, height: h * scale,
    backgroundImage: `url(${src})`,
    backgroundSize: `${w * 10 * scale}px ${h * 11 * scale}px`,
    backgroundPosition: `-${(n % 10) * w * scale}px -${Math.floor(n / 10) * h * scale}px`,
    imageRendering: "pixelated" as const,
  };
}
export const SEATS = ["#e5533f", "#3b82f0", "#44b860", "#f0c030", "#9b6ad6", "#f08a2e", "#36c2c9", "#f06aa8", "#eeeae0", "#4a4f5c"];
export const avatarArt = (seat: number) => `${ROOT}avatars/avatar-${seat % 10}.png`;
export const sceneFor = (room: string, theme: "night" | "day") => {
  let hash = 0; for (const c of room) hash = (hash * 31 + c.charCodeAt(0)) >>> 0;
  return `${ROOT}scene/${theme}-${hash % 2}.png`;
};
```

图片地址固定，换图后靠服务器给 `/art/` 加 `Cache-Control: no-cache`（模板已有）。

## 8. 出图阶段的做法（预计 $3–6，开工样张已花 $0.27）

定稿放 `art/out/final/<spec 路径>`，见文件开头。

| 素材 | 做法 | 候选 |
|---|---|---|
| 夜间场景 ×2 | bitforge 局部重绘去掉 s32 墙上的两个牛头骨（换马蹄铁 / 牛仔帽）+ pixen 新种子（提示词去掉 mounted longhorn horns，加 horseshoes, cowboy hats, coiled lasso on wall hooks） | ≥4 |
| 白天场景 ×2 | s42 + pixen 新种子；检查吊着的空木牌上没有乱码 | ≥4 |
| hero | 选中的夜间场景，或 pixen 出一张酒馆门口 | ≥3 |
| 牛头图标 16 / 32 | `/generate-image-v2` 各一批 64 个（可爱圆脸、小角、大眼，避开凶红牛头），挑 3+ 进画廊 | 64 → 3+ |
| 牌面 | 代码（`art/cards.py`，从 placeholders 的画法起步），小牛脸用选中的图标手工缩；整套图集作为**一个选项**，出 3 种底纹 / 角花方案 | 3 |
| 牌背 | 代码版 + pixflux 图案版 | ≥3 |
| 毡面、木边 | pixflux 出纹理再修成无缝 / 九宫格；代码版保底 | ≥3 |
| 空格、危险格 | 代码，3 种变体 | 3 |
| thinking / ready / lasso / star / king-bull / poster | v2 一批 64 个（king-bull 48px 超过 v2 的 42px 上限，用 pixflux 或 v2 出 40px 再放进 48 画布） | 各 3+ |
| 头像 ×10 | v2，每种动物一批或带风格参考；围巾按座位色用色相蒙版换色（蒙版只限围巾） | 每只 3+ |
| 动画 ×7 | `/animate-with-text-v3`，首帧末帧用选中的静态图；`finalize.py report` + 坏帧检查 | 各 3 |
| 封面 | `game-center/art/covers.py` 风格，384×192 | 3 |
